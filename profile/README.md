# Squeeze Labs

Independent financial data engineering and quantitative research.

Squeeze is a privately developed research platform for collecting, processing, and analyzing financial market, news, and economic data. It provides the infrastructure for personal research, experimentation, and machine learning.

The platform is actively developed, with research and selected technical work shared publicly.
